# Claude Camp Week 01 Practice

This folder contains five small Python practice scripts and one Jupyter Notebook summary.

## Exercises

1. `exercise_1_temperature_converter.py`  
   Converts temperatures between Celsius and Fahrenheit.

2. `exercise_2_personalized_greeting.py`  
   Takes a name and age, then prints a personalized greeting message.

3. `exercise_3_tip_calculator.py`  
   Calculates the tip amount and total bill from a bill amount and tip percentage.

4. `exercise_4_password_generator.py`  
   Generates a random password based on the length entered by the user.

5. `exercise_5_bmi_calculator.py`  
   Calculates BMI from height and weight, then prints a simple health suggestion.

## How to Run

Run any script with Python:

```bash
python3 exercise_1_temperature_converter.py
python3 exercise_2_personalized_greeting.py
python3 exercise_3_tip_calculator.py
python3 exercise_4_password_generator.py
python3 exercise_5_bmi_calculator.py
```

You can also open `week1_practice.ipynb` in Jupyter Notebook, VS Code, or GitHub to view all five exercises with clear sample outputs.
