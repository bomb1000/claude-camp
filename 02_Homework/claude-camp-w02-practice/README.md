# Claude Camp Week 02 Practice

This folder contains four Python practice scripts and one Jupyter Notebook summary.

## Exercises

1. `exercise_1_roster_manager.py`  
   Manages a student roster with add, search, and delete actions using a dictionary.

2. `exercise_2_word_frequency.py`  
   Counts word frequency from text, ignores case, and prints results sorted by count.

3. `exercise_3_todo_list.py`  
   Adds, completes, and views todos while saving data to a local `todos.json` file.

4. `exercise_4_safe_calculator.py`  
   Runs a safe calculator that handles invalid numbers, division by zero, and `quit`.

## How to Run

Run any script with Python:

```bash
python3 exercise_1_roster_manager.py
python3 exercise_2_word_frequency.py
python3 exercise_3_todo_list.py
python3 exercise_4_safe_calculator.py
```

Open `week2_practice.ipynb` in Jupyter Notebook, VS Code, or GitHub to view all four exercises with sample outputs.
