# Claude Camp

This repository is organized for course notes, homework, shared resources, and a final project.

## Folder Structure

- `01_Notes/` - weekly learning notes, practice files, and in-class exercises
- `02_Homework/` - homework submissions organized by assignment
- `03_Resources/` - useful links, datasets, prompts, and references
- `04_Final_Project/` - final project planning, drafts, and deliverables
